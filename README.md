The Clockmaker's Atelier: five original canvas illustrations, forty differences, and a collection of small wonders. Includes timed hunts, streak scoring, clues, synthesized sound, keyboard controls, and saved personal records. Every scene is drawn locally in code.

## Run it

```sh
node serve.ts
```

Open localhost:8080. Click a change in either picture; gold rings mark both. Find all eight before time runs out. A miss costs five seconds. H gives a three-second clue without solving it. Arrows move the crosshair, Space guesses, Tab changes panel, P pauses, R retries, M toggles sound, and 1–5 selects a scene.
